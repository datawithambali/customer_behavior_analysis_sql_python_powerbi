# 📊 Customer Behavior Analysis Project

## 🔍 Overview

This project demonstrates an end-to-end data analytics workflow, from raw data processing to insight generation. It focuses on cleaning, exploring, and analyzing data to uncover trends and support data-driven decision-making using Python, SQL, and Power BI.

---

## 📁 Dataset

* Structured dataset containing numerical and categorical variables
* Includes fields used to analyze performance, trends, and key business metrics
* Used across Python, PostgreSQL, and Power BI for analysis and visualization

---

## 🛠️ Tools

* **Python** – Pandas
* **PostgreSQL** – Data querying and aggregation
* **Power BI** – Dashboard and visualization
* **Gamma** – Presentation of insights

---

## ⚙️ Workflow

**1. Data Loading & Cleaning**

* Imported dataset using Pandas
* Checked data types and structure
* Handled missing values 
* Standardized formats for consistency

**2. Exploratory Data Analysis (EDA)**

* Analyzed data distributions and feature relationships
* Used visualizations to identify trends and patterns
* Detected outliers and anomalies
* Explored key variables impacting overall performance

**3. SQL Analysis (PostgreSQL)**

* Loaded cleaned data into PostgreSQL
* Wrote queries for aggregations, filtering, and metric calculations
* Extracted insights to answer key analytical questions

**4. Dashboard & Reporting**

* Built an interactive Power BI dashboard with KPIs and charts
* Added filters for better data exploration
* Summarized findings in a report and presentation

---

## 📊 Dashboard

* Displays key metrics, trends, and comparisons
* Interactive visuals for quick and clear insight extraction

---

## 📈 Key Findings

* Identified important trends and seasonality in the data
* Highlighted top-performing and underperforming segments
* Detected data patterns through EDA
* Generated actionable insights using SQL and visual analysis

---

## 🚀 How to Run

* Run Jupyter Notebook for Python analysis
* Execute SQL queries in PostgreSQL
* Open Power BI (`.pbix`) file to view dashboard
